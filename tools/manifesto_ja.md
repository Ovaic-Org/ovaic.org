# 会員が支える
OVAICは、創設した人を含め、どの一人よりも長く続くように作られています。

## 1. 会費がある理由
他者を検証する組織は、一人の後援者に依存してはなりません。一人がすべてを支払えば、その活動はその人が続く間しか続かず、その人の望みに傾きます。会費によって、会員はこの活動を必要とし、続いてほしいと示します。各会員が一部を担うことで、誰も全体を一人で担わずに済みます。

## 2. 会費で権力は買えない
- 会費の額にかかわらず、一会員一票。
- 会費はOVAIC自身の口座にのみ入り、発起人には決して入りません。
- すべての支払いは記帳され、年次決算に示されます。
- いくら支払っても、自らに関する結果を決める会員はいません。

## 3. 発起人の役割
Gravit Open Network FoundationがOVAICを立ち上げました。同財団は他のすべての会員と同じ条件の一会員であり、特別な権利を持ちません。

その創設者であるDr. Alex Konviserは、事務局長としてOVAICに仕えます。助言、作業、組織運営によってです。事務局長はOVAICを指揮せず、影響力と引き換えに資金を出さず、結果を決めません。創設者であることは、ここでは何の権限も与えません。決定は会員と、会員が選ぶ理事会に属します。最初の通常総会までに、理事会の過半数は発起人から独立した組織から選ばれます。

## 4. 世代を超えて
良い回路は、一つの部品を交換しても動き続けます。どの部品も単独で回路を支えていないからです。OVAICも同じように機能することを目指します。公開された定款、公開された手法、公開された結果、会員が選ぶ理事会、そして多くの人で分かち合う支え。そうすれば、活動は一人の人生とともに終わることはありません。
