# ovaic.org

Source of https://ovaic.org, the website of the Open Verifiable AI Consortium (OVAIC), Zurich.

This repository is the public record of OVAIC: every text, every change and its reason. Nothing is rewritten; corrections are added. See https://ovaic.org/record/

## Propose a change
Open an issue or a pull request. Each proposal stays visible with its discussion, whether it is accepted or not. Changes to the statutes, the charter and the fees are decided by the bodies named in the statutes.

## Build
`python3 tools/build.py` from the repository root builds all 22 languages from the sources in `tools/`.

## History
The public record begins with this first commit on 1 November 2026, which holds the site as it stood that day. Earlier working versions are kept in the association's archive.
