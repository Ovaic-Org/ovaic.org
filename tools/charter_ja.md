# Open Verifiable AI Consortium (OVAIC)

**憲章、2026年10月19日に設立メンバーにより採択**

## 1. 目的
AI システムはすでに、お金を動かし、公共の情報を形づくり、人々に代わって行動する判断を下しています。これらの判断への信頼は、システムを運用する当事者の言葉だけに頼るべきではありません。

OVAIC は、AI の主張と判断を独立して検証できるようにする手法を開発し試験する組織を結集します。どの証拠が使われたか、誰が署名したか、情報源は独立しているか、そして誰でも結果を再現できるか。

私たちは未来の世代のために築きます。目指すのは利益ではなく、どの企業よりも長く続く公共の価値です。

## 2. 私たちの活動
1. **オープンなテストベッド：** 共有の公開テストケース（攻撃、境界事例、実データ）。メンバーのどの手法もここで実行し比較できます。
2. **相互運用性プロファイル：** 署名付き証拠、来歴記録、オラクルデータ、計算の証明、透明性の受領証がどう組み合わさるか。
3. **共同報告：** コードとデータとともに公開する、再現可能な結果。
4. **オープンな標準への貢献**（IETF、W3C、C2PA など）：メンバーが自らの名で行います。

## 3. 原則
1. **独立性：** どのメンバー、ブロックチェーン、AI ベンダー、認証機関も、コンソーシアムやその結果を支配しません。
2. **再現性：** 主張は、公開されたコードとデータから他者が再現できる場合にのみ認められます。
3. **開かれた訂正：** 誤りは公開の場で、発見者の名を挙げて訂正されます。メンバー自身の手法に不利な発見も歓迎します。
4. **多様性：** メンバーは異なる手法を比較します。OVAIC は一つの技術を勝者とはしません。
5. **信頼性を判定しない：** OVAIC は手法と試験結果を公表します。いかなるシステムや人物が信頼できると認証することはありません。

## 4. メンバーシップ
- **メンバー：** 検証、来歴、評価、エージェントの信頼に取り組む企業、プロトコル、研究グループ、非営利団体。平等な権利、各一票。
- **オブザーバー：** 標準化団体、規制当局、個人の専門家。議決権はありません。
- **参加：** 短い申請と本憲章の承諾。会費規程に基づき、規模に応じた年会費。
- **利益相反：** 各メンバーは自らの製品を申告します。メンバーは自らの手法に関わる結果については投票しません。

## 5. ガバナンス
- **総会：** 全メンバー。憲章、予算、入会を決定します。
- **運営委員会：** 異なる組織と地域から一年任期で選ばれる五人から七人。一つの組織が複数の席を持つことはありません。
- **作業部会：** 全メンバーに開かれ、結果はオープンライセンスで公開されます（コードは Apache 2.0、文書は CC BY 4.0）。
- **決定：** 可能な限り合意により、それ以外は三分の二の多数により。

## 6. 法的形態
チューリッヒに本拠を置くスイス法上の社団（*Verein*）。設立メンバーが定款に署名し、その後は誰でも同じ条件で参加できます。

## 7. 発起人
Gravit Open Network Foundation が OVAIC を発起し、他のすべてのメンバーと同じ条件で一メンバーとして参加します。特別な権利は持ちません。

## 8. 最初の一年
1. 最初のメンバーによる設立会議（オンライン）。
2. 最初の共有ケースを備えた公開テストベッド。
3. 最初の共同報告。
4. チューリッヒでの定款登記。
