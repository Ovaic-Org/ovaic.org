# 公開記録
OVAICが決定し公開するすべてのことは公開の場で記録され、何も書き換えられません。

## 1. なぜ記録なのか
他者を検証する組織は、それ自身が検証可能でなければなりません。このサイトのすべての文章、すべての変更とその理由は、コードと同じように公開リポジトリに保存されます。誤りは訂正を追加することで正し、以前の記述を消すことは決してありません。

## 2. 変更の進め方
- 誰でも、プルリクエストまたはイシューとして変更を提案できます。
- 各提案は、採用されてもされなくても、その議論とともに公開されたまま残ります。
- 定款、憲章、会費の変更は、定款に定める機関が決定します。記録には、誰がいつ決定したかが示されます。
- 将来のプロトコルや将来のインフラの候補も、テストケースとともに同じ方法で提案されます。候補がどのように生まれ、なぜ採用または保留されたかを、誰もが見られるようにするためです。

## 3. その由来
この目的は2015年、分散型の原則の集まりであるDecipialにさかのぼります。それ以来、手法も技術も変わりました。しかし目的は変わっていません。すべての人が情報にアクセスできるようにすること、すべての人が保護された情報にアクセスできるようにすること、そしてそれを目の中に入れても痛くないほど大切に守ることです。

## 4. 尊厳と情報への権利
ドイツ基本法は次の言葉で始まります。「人間の尊厳は不可侵である。これを尊重し、保護することは、すべての国家権力の義務である。」（第1条）。また、「一般に近づくことのできる情報源から妨げられることなく知る」権利を保障しています（第5条）。世界人権宣言は、すべての人に情報を求め、受け、伝える自由を認めています（第19条）。国家と共同体は、これを守り、その上に築き、助けなければなりません。OVAICは、主張を公開の場で、すべての人にとって検証可能にすることで貢献します。

## 5. 後に続く人々へのメッセージ
私たちは、先の世代が築いた豊かさの中で生きています。その豊かさとともに、一つのメッセージを手渡したいと考えます。より良く、より意識的に、より品位をもって生き、文明の共同体全体のために善を生み出してほしい、と。公開記録は、私たちが約束を守るための方法です。
